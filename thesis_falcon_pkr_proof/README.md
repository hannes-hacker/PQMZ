# PQC-project- EasyCrypt Formalisation


This repository contains the first machine-checked formalisation of PKR security reduction in EasyCrypt.

Installation instructions for EasyCrypt are available on the EasyCrypt [GitHub repository](https://github.com/EasyCrypt/easycrypt).


## Repository Structure

- `falcon.ec`  
  Main EasyCrypt development for the PKR security reduction.

- `easycrypt-zk-code/`, `easycrypt-rewinding/`  
  Supporting libraries and dependencies for zero-knowledge and rewinding arguments.

- `fsec/`  
  Formalisation repo of the [Forking Lemma](https://eprint.iacr.org/2025/573.pdf).
